# Draft-vs-sent pair

Use this file when the vault owner edited an agent's draft before they sent
it. The difference between the two is a lesson about how they write. Do steps
1 to 4 in order. Then go back to the skill's `SKILL.md` step 4.

1. Save the draft and the sent text, one after the other, to
   `sources/YYYY-MM-DD-<slug>-draft-vs-sent.md`. Redact it (the skill's
   `SKILL.md` step 1).
2. Compare the two. List each change the owner made: a cut, a rewording, an
   addition or a new order. Ignore a change that only corrects a fact.
3. Write the lesson behind each change as one short rule on the owner's style
   page, `topics/my-communication-style.md`. Cite the source file from step 1.
   - The page has a rule that says the same → sharpen that rule. Never add a
     second copy.
   - The vault has no style page → create it with the schema in AGENTS.md →
     "Entity schemas" (`type: topic`), with these rules as its first content.
4. Set `updated:` to today on the style page.
