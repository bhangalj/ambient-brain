# AGENTS.md — how to read and write this vault

This is a work-only second brain: a private, git-backed Obsidian vault that
ingests meetings, Linear, Slack, email, and dictated brain-dumps, and serves
them back as current context. **This repo is the single source of truth** —
nothing holds state that isn't in (or derivable from) it.

## Answering "what's the state of X?"

Read in this order; stop as soon as you have enough:

1. **`DASHBOARD.md`** — portfolio view: projects by status, open action count, ideas queue.
2. **`02-projects/<slug>/_project.md` → `## Current state`** — the maintained
   ~500-token digest: status, recent decisions, open threads, links deeper.
   This is usually all you need.
3. **Depth inside the vault** — `02-projects/<slug>/tasks/` (one note per Linear
   issue), `done.md` (completed-work log), `03-meetings/` (decisions in context).
4. **Full technical depth** — the code repos listed in the project's
   frontmatter `repos:`. The vault is the hub; repos are the spokes.

For people: `04-people/<slug>.md`. For loose todos: `00-inbox/actions.md`.

## Layout

| Path | Holds |
|---|---|

| `DASHBOARD.md` | auto-maintained portfolio view; regenerated by every sync |
| `00-inbox/` | `actions.md` (todos + source msg ids) · `transcripts/` · `braindumps/` |
| `01-daily/` | daily notes; brain-dumps default here |
| `02-projects/<slug>/` | `_project.md` (digest + docs hub) · `tasks/` (Linear issues) · `done.md` |

| `scripts/` `webhook/` | syncs, ingest, hooks, `lib/` · always-on vault service |

## Conventions

- **Frontmatter on every note.** Base keys: `type`, `date`, `project`,
  `people`, `source` (per-type extras allowed).
- **Wikilinks for every person/project mention**: `[[jane-doe]]`,
  `[[my-project/_project|My Project]]`. This is the link graph — don't skip it.
- **Kebab-case slugs that NEVER change.** Slugs are identity; renaming breaks
  every wikilink and every agent's memory of the vault.
- **Dates are `YYYY-MM-DD`.**
- **Encoding: always UTF-8** in any script touching notes (Windows defaults to
  cp1252 and corrupts wikilinks) — pass `encoding="utf-8"` explicitly.

Project note (`02-projects/<slug>/_project.md`):

```yaml
---
type: project
name: My Project
status: active          # active | paused | done | idea
repos: [https://github.com/org/repo]   # spokes — full technical depth
people: ["[[jane-doe]]"]
created: 2026-07-05
---
```
Body sections: `## Current state` (THE DIGEST) · `## How it works` (docs hub)
· `## Decisions` · `## Ideas / future` · `## Log` (append-only activity trail).

Task note (`02-projects/<slug>/tasks/<ID>.md`, one per Linear issue):

```yaml
---
type: task
source: linear
id: ENG-123
title: Fix the thing
status: In Progress
project: "[[my-project/_project|My Project]]"
url: https://linear.app/...
date: 2026-07-05
---
```

## Write rules

Three writers share the repo:

| Writer | When | Mechanism |
|---|---|---|
| Me, in Obsidian | ad hoc | obsidian-git: auto-pull on open, auto-commit+push ~10 min |
| Claude Code, local | end of any turn that touched the vault | Stop hook `scripts/session_capture.py`: one batched add/commit/rebase/push |
| Automation (CI syncs, webhook, MCP) | scheduled / per event | `pull --rebase` before push, retry once; appends only to machine-owned paths |

**Machine-owned, append-only paths** (automation and agents write here freely):
`00-inbox/`, `02-projects/*/tasks/`, `03-meetings/_raw/`, `06-interactions/`,
`99-meta/`, plus the `## Current state` digest sections and `DASHBOARD.md`.

**THE INVARIANT — every writer leaves the digest current.** Any write into a
project MUST refresh that project's `## Current state` AND `DASHBOARD.md` in
the same commit. Use `scripts/lib/vault.py`:

- `ensure_project(name)` — create the project skeleton if absent
- `refresh_digest(slug)` — rewrite that project's `## Current state`
- `regenerate_dashboard()` — rebuild `DASHBOARD.md`

**Batched commits only**: `git add -A` → commit → `pull --rebase` → push.
The Stop hook does this automatically for Claude Code sessions; use
`scripts/lib/gitsync.sync_repo` for anything else. Never commit per-file.

## Never

- Hold state outside the repo — no caches, no side files, no second store.
- Rename slugs, files, or folders. Paths are permanent identity.
- Rewrite human-owned prose. `## How it works` and `## Decisions` are
  human+agent curated — **append, don't rewrite**.
- Commit per-file, push without `pull --rebase`, or skip the digest refresh.
- Write notes without frontmatter or without wikilinking people/projects.

## Pointers

- `DESIGN.md` — architecture and rationale (the decision log is final)
- `README.md` — setup: tokens, config, CI, Obsidian plugins
- `templates/` — note shapes for meeting, person, project, feedback
